# 手动 E2E 检查清单

## 启动

```powershell
cd apps\vision-demo
$env:OPENROUTER_API_KEY="你的 OpenRouter key"
npm run serve
```

打开 `http://127.0.0.1:8787`。

注意：这是 OpenRouter 云端辅助演示。点击识别会把当前帧发送到 OpenRouter；真实儿童数据默认不要用于这个流程。

## 摄像头实景测试

1. 点击 `启用摄像头`。
2. 将画面对准非敏感的蒙氏空间或模拟教具场景。
3. 点击 `截取`。
4. 点击 `识别`。
5. 检查活动、类别、置信度、复核标记和 JSON 是否符合可见证据。
6. 只在确认无隐私问题时点击 `保存日志`。

## 样张回归测试

1. 选择任意样张。
2. 点击 `识别`。
3. 对照 `../../research/montessori-frame-eval/answer_key.md` 检查模型是否抓住核心活动。

## 通过标准

- 不出现儿童身份、人脸识别、情绪判断、诊断或评分。
- 活动标签能落入标准标签集。
- 安全和环境线索不会被写成确定性育儿建议。
- 保存的日志只有结构化结果，没有原始图片。
