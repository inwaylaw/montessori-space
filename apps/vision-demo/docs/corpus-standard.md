# 蒙氏空间视觉识别语料标准 v0.1

## 目标

本标准只服务于示范性视觉识别流程：把一帧或少量连续帧转成可复核的蒙氏活动观察记录，并用合成样本测试模型能力。它不是儿童评价、诊断、情绪识别或成长结论系统。

## 允许采集的信息

- 可见活动：取用教具、操作教具、归位、等待、混合活动。
- 可见材料：粉红塔、红棒、串珠、倒水托盘、剪纸材料等。
- 工作区域：地垫、桌面、教具架、多个工作区、未知。
- 环境线索：水滴、物品未归位、工作区数量、空间方位。
- 安全线索：剪刀、打翻液体等需要家长确认的物品或状态。
- 人工复核字段：家长或教师后续确认、纠正、备注。

## 禁止采集的信息

- 儿童姓名、人脸身份、家庭地址、可识别家庭空间细节。
- 情绪推断，例如开心、焦虑、沮丧。
- 能力评分、人格判断、医学或发育诊断。
- 未经脱敏的真实儿童原始图片、视频、音频。

## 标注对象

一个语料条目建议包含：

```json
{
  "id": "ms_001",
  "source_type": "synthetic_frame",
  "images": ["images/01_pink_tower_mat.png"],
  "question": "这一帧最可能记录的是哪种蒙氏教具活动？",
  "expected_answer": "粉红塔",
  "answer_type": "contains_any",
  "acceptable_answers": ["粉红塔", "pink tower"],
  "expected_keywords": []
}
```

模型输出统一采用 `schemas/montessori_observation.schema.json`。其中 `test_answer` 用于自动评分，`observation` 用于产品流程复核。

## 标签集

活动类别：

- `practical_life`: 倒水、夹取、切割、清洁等实用生活活动。
- `sensorial`: 粉红塔、红棒、颜色或大小辨别等感官材料活动。
- `language`: 字卡、阅读、命名、听说相关活动。
- `math`: 数棒、串珠、计数、数量对应等活动。
- `art`: 剪纸、绘画、拼贴等美工活动。
- `movement`: 粗大动作或空间移动活动。
- `order_return`: 取用、整理、归位、秩序线索。
- `environment`: 工作区、空间布局、环境异常或安全线索。
- `unknown`: 画面证据不足。

动作标签：

- `taking_material`
- `working`
- `returning_material`
- `waiting`
- `mixed`
- `unknown`

工作区标签：

- `floor_mat`
- `table`
- `shelf`
- `multiple`
- `unknown`

## 质量规则

- 每条样本至少有一个明确预期答案，且答案可由画面直接支持。
- 可接受答案应覆盖中英文别名和常见短答案。
- 多帧样本必须按时间顺序列出图片。
- 自动评分只做初筛；中文同义表达需要人工复核。
- 真实 E2E 只能保存结构化观察，不默认保存原始帧。

## 当前测试覆盖

`testset/testset.jsonl` 包含 15 条合成蒙氏帧任务，覆盖教具识别、工作区识别、实用生活活动、归位秩序、安全线索、观察边界、多帧顺序、报告读取。
